# Sprite Rig Lab

Sprite Rig Lab is a deterministic browser tool for turning one transparent PNG sprite into a floor-locked animation strip.

## Current scope
- Upload PNG sprite and analyze alpha bounds/floor.
- Generate 5/6 frame idle strip in equal cells.
- Export transparent PNG strip and metadata JSON.

## Scripts
- `npm run dev`
- `npm run build`
- `npm run preview`
- `npm run typecheck`
